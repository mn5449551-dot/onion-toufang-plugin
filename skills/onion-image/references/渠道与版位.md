# 渠道与版位索引

> 这是路由索引。完整结构化规则在 `../config/channel-placement-rules.json`（2026-05-18 整理自《厂商&学习机素材规范汇总》rev320，原始整理稿仅维护人溯源）；字段含义、一期开放规则、render/target 处理链路和多版位原则统一见 `版位比例与尺寸.md`，不在本文件重复。

## 什么时候读哪份

| 当前问题 | 读取 |
|---|---|
| 用户给了渠道但没给版位 | `版位比例与尺寸.md` 和配置页 |
| 需要确定 `render.py --size` | `../config/channel-placement-rules.json` 的 `render_size` |
| 需要导出目标尺寸和 KB | `../config/channel-placement-rules.json` 的 `target_size` / `max_file_size_kb` |
| 同一文案要出多个渠道/版位 | 配置页多选版位；多版位原则见 `版位比例与尺寸.md` |
| 要写渠道化 prompt 风格、看跑量复盘 | `渠道风格与复盘.md` |

## 唯一在本文件维护的提醒

各家渠道规则会变，实际投放前以投放后台当前规格为准；插件内规则是生成和入库阶段的工作基准。
