# 文案渠道规范（信息流 / 应用商店 / 学习机）

> 出文案 skill 按当前渠道看对应章节。用户不指定人群时，**默认学生视角**；业务核心是 APP 图文，文案要让学生看见具体场景、具体问题和洋葱的产品动作。

## 全局心法

面向学生时，先做 `具体场景 + 具体情绪 + 产品动作 + 可感知变化` 的判断。学生第一视角不是强制写“我”，而是让学生看到自己的处境、语言和在意的结果。

| 目标 | 怎么写 |
|---|---|
| 锁定具体场景 + 具体问题 | 写出“晚上作业卡壳”“拍了三遍还不准”“看答案解析更懵”等能让学生觉得“是我”的瞬间 |
| 惊艳解法 | 用产品动作解释洋葱怎么解决：`洋葱一拍`、`洋葱拍题精学`、`分步解析`、`看不懂再问 AI`、`5-8 分钟动画课` |
| 场景奇效 | 写生活/情绪的具体变化：作业不再卡一晚、卡在哪步就问哪步、先测出薄弱点再学 |
| 产品锚定 | 每套文案至少让人知道“谁在解决、怎么解决”，避免只写“学习神器”“高效掌握” |

默认先建立 `具体场景 + 产品动作 + 可感知变化` 的理解，再按单图、双图、三图选择表达关系。`场景问题 -> 惊艳解法 -> 场景奇效` 是一种可用思路，不是所有文案的固定结构。

产品动作必须匹配当前功能：`30 分钟课堂`、`AI+真人答疑/辅导`、`先测再学/诊断分班` 是洋葱私教班、AI定制班的专属口径，只有当前功能是它们时才能写（功能边界详见 `../../../shared/references/creative-brief.md`）；拍题类文案的产品动作是 `洋葱一拍`、`分步解析`、`看不懂再问 AI`。

## 表达红线（运营反馈，表达层最高优先级）

与本文件或其他风格规则冲突时，按本节执行；用户明确要求的措辞除外。

**1. 场景要具体**：要有时间、动作、具体学习任务和卡住的瞬间，不能只贴"期末/暑假"节点标签。"暑假想补基础"不合格；"暑假想查漏补缺，一翻书直接懵了"合格。

**2. 学生话，不写产品腔**：下表左列默认不用，换成学生会说的话。卖点库和方向卡里的**能力描述**（如"AI 定制学习路径"）和**场景措辞**（如"卡在一个小地方"）都是内部口径，写进文案前必须从场景理解出发重新用学生口语组织，不能直接截取或压缩原文。

| 默认不用（产品腔） | 换成（学生话） |
|---|---|
| 补弱 | 补短板、哪儿不会先补哪儿 |
| 学习路径、重点规划 | 先补哪、今天先学啥、每天学什么一眼清楚 |
| 高效学、精准补救 | 不绕弯、不白忙、越学越有方向 |
| 定制提分 | 按你的薄弱点排、哪儿丢分补哪儿 |

机械换皮无效：把"学习路径"改成"学习路线/学习地图"仍是产品腔。判断标准只有一个——学生口语里会不会这么说。

**3. 学生吐槽视角与网感**：这是人群视角规则，不是渠道专属规则。目标人群是学生，或用户未指定人群而走默认学生视角时，先读 `学生视角与网感.md` 判断痛点侧是否有天然匹配的学生吐槽或梗；没有天然匹配时不用梗，只保留学生口语和具体场景。

**4. 陪伴感不是监督感**：写"卡住有人慢慢讲、不催不赶、可反复问、懂了再做下一题"；不写"老师盯着你/监督你完成/有人督促"。

## 信息流

> 信息流用户被动看到广告，需要强钩子打断浏览注意力，但仍要默认学生视角，不写成家长汇报或品牌宣传稿。
> 信息流只支持单图（主标题 + 副标题）；当前出图版位只有趣头条和网易的单图位，没有双/三图。

### 语气规则

| 特征 | 怎么写 |
|---|---|
| 钩子起手 | 主标题 = 学生当下痛点 + 明显情绪，用疑问 / 感叹，例如“拍了改、改了拍，识别不出来？”；不写说明句 |
| 情绪锚点 | 抓“卡壳 / 看不懂 / 懵 / 烦 / 作业还没写完”等情绪，写到位但不夸张（强度和零推断要求见「表达红线」） |
| 画面感 | 放进具体时刻：晚上 9 点、周末作业、考前两周、错题订正 |
| 产品动作 | 副标题 = 洋葱功能 + 解决动作，承接“用洋葱一拍、分步解析、看不懂再问 AI”，不只堆功能名 |

### 变体节奏

3 套以上时，主标题套路要拉开：

| 套 | 主标题套路 | 例 |
|---|---|---|
| 1 | 具体卡点 | 拍了改、改了拍，识别不出来？ |
| 2 | 反问质疑 | 看完答案解析更懵了？ |
| 3 | 时间压力 | 作业还剩亿点点？ |
| 4（可选） | 旧体验 vs 新解法 | 解析又长又没重点？ |
| 5（可选） | 情绪直给 | 一道题卡半小时，烦到想扔笔！ |

同批主标题不要全部用问号收尾，疑问 / 直给 / 感叹穿插。副标题可用承接解法、加细节、结果导向三类，但必须补足产品主体和产品动作，且同批副标题不要共用一个句式（落点轮换见 `规格.md` 多套生成）。

## 应用商店 / 学习机单图

> 应用商店和学习机的单图文案共用同一套逻辑：学生视角、口语化、有画面感、说清功能好在哪里。学习机只支持单图；应用商店保留单图、双图、三图。

### 共用单图写法

| 维度 | 规则 |
|---|---|
| 起手 | 可以直白，也可以痛点问句；不要太品牌腔 |
| 情绪 | 让学生觉得“这就是我现在遇到的问题”，情绪要写出来（懵、烦、卡住），不痛不痒不行；不是家长视角的省心宣传 |
| 画面 | 具体到作业、错题、课堂没听懂、考前复习、晚上无人答疑 |
| 产品动作 | 优先写当前功能真实的可感知动作：拍题类写“洋葱一拍”“洋葱拍题精学”“分步解析”；私教班/AI定制班才写“先测再学”“30 分钟课堂”“AI+真人答疑” |
| 结果 | 写“卡在哪步就问哪步”“薄弱点先测出来”“晚上难题不过夜”等具体变化 |

应用商店 / 学习机单图可展示为：

```markdown
**应用商店 / 学习机 · 单图**

| 编号 | 主标题 | 副标题 |
|---|---|---|
| 文案 1 | 收藏从未停止，学习从未开始 | 别囤了，洋葱 AI 挑出你真该学的那块 |
```

（示例解析：痛点句是学生原话级吐槽且与"囤资料不学"的痛点天然一对；解法句是产品直白接话。示例风格会过期，按运营最新案例校准，不照抄句式。）

### 私教班口径

涉及洋葱私教班时，读取 `../../../shared/knowledge/功能-洋葱私教班.md`。手册里的提分、100%紧贴校内大纲、4 周特训等表达可以作为业务口径吸收；不要把私教班事实误写到拍题精学里。

## 避免的写法

| 避免 | 为啥 |
|---|---|
| `K12 学生必备` | 太泛，没有学生画面感 |
| `高效学习神器` | 空泛，没说产品动作 |
| `妈妈省心，家长放心` | 默认学生视角下会变成家长腔 |
| `题不会做 / 拍一下 / 当场会` | 用户记不住“谁在解决”和“怎么解决” |
| 把私教班卖点写进拍题精学 | 产品事实错位 |

## 学段语气

- 小学高年级：可以更轻松、趣味。
- 初中：直接，允许一点同侪感。
- 高中：平等、干货，不哄人。
- 中职：务实，围绕职教高考、对口升学、技能证等路径。
