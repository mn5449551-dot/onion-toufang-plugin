# 学生视角与网感

本文件是学生向文案的表达资产，不属于某个渠道。只要目标人群是学生，或用户未指定人群而走默认学生视角，生成前都先读本文件，判断痛点侧是否有天然匹配的学生吐槽或梗。

使用目标不是强制每条文案塞网感词。没有天然匹配时，不用梗，只保留学生口语、具体场景和真实情绪。表外的梗不是禁区：运营当下给的案例优先，新梗过了文末四个自检就能用。

## 核心原则

广告要让学生觉得"这说的就是我"。共鸣来自语言身份认同：痛点句要写成学生自己会发的那条吐槽，而不是大人替学生总结的病情。

| 判断 | 原则 |
|---|---|
| 痛点侧 | 学生在吐槽。可以用真实网络语言和梗自嘲，自带"期待 -> 现实"的反差微叙事，痛而好笑，不卖惨不恐吓 |
| 解法侧 | 产品在接话。大白话直给，一句说清产品动作；动作顺序必须符合真实使用流程，不跳步 |
| 梗的使用 | 梗和痛点要天然一对。与痛点无关的热词硬塞只会尬。自嘲可以，指向他人的攻击不行 |
| 时效 | 取材以用户/运营当下提供的案例和平台语感为准；过时的梗比没有梗更尬 |

例子：`三科都有漏洞，先补哪个？` 是诊断腔；`收藏从未停止，学习从未开始` 更像学生自己的吐槽。

解法侧最多顺着痛点的梗接一下，例如 `原地打转 -> 不绕路`；不要另起炉灶玩梗。梗负责"像我"，直白负责"可信"，缺一边都不成立。

## 痛点适配库

先选痛点，再选吐槽表达。表里的文案是写法种子，不是固定句式；生成时要换成当前功能、学段、渠道和方向卡里的真实场景。带 * 的是 2025-2026 时效梗，一旦显旧立刻停用，以运营最新案例为准。

| 痛点场景 | 可用吐槽 / 网感表达 | 痛点句写法种子 | 解法侧怎么接 |
|---|---|---|---|
| 计划立了但执行不了 | 立 flag、原地散架、三分钟热度、列了贴了忘了、画饼、从从容容/连滚带爬* | 暑假 flag 立了一页，第三天就不想学了？ | 接"每天学什么已经排好"、"打开就知道先做哪步"，不要写监督盯人 |
| 囤资料/囤课但不开始 | 收藏从未停止，学习从未开始；主打一个想学但没动；预制复习* | 收藏从未停止，学习从未开始？ | 接"别囤了，先挑出今天真该学的那块"，强调筛选和开始 |
| 想查漏补缺但不知道漏哪 | 查了个寂寞、内耗、原地打转、我去不早说* | 别人查漏补缺，我查了个寂寞？ | 接"先测出薄弱点，再安排先补哪"，必须先测再补 |
| 多科都弱，不知道先救谁 | 拉胯、先救哪科、CPU 烧了 | 数学英语都拉胯，先救哪科？ | 接"洋葱先帮你测，哪科弱先补哪科"，别直接跳到结论 |
| 复习没方向，只会乱刷 | 玄学、开盲盒、原地打转、邪修*、真没空陪你闹了* | 复习全靠玄学，刷题全靠缘分？ | 接"按薄弱点排重点/按高频考点练"，落到不乱刷；可用"听劝"引导换方法；用"邪修"时先测再补要显得聪明，不能像歪门邪道 |
| 错题本一翻就崩 | 破防、天塌了、汗流浃背、没绷住、名场面 | 错题本一翻开，当场破大防？ | 接"先看错在哪，再练同类题"，强调复盘和减少同类错 |
| 课堂听懂，自己做不会 | 一听就会，一做就废；脑子会了，手不会；这题我熟，一做全错；XX 基础，XX 不基础*；下笔就卡；课上 NPC 式点头 | 上课一听就会，练习一做就废？ | 接"拆步骤/讲思路/同类题练会"，不要只说高效掌握 |
| 题目卡住，对答案也没用 | 大眼瞪小眼、干瞪眼、卡半天 | 一道题憋半天，和答案干瞪眼？ | 拍题类接"洋葱一拍讲思路"；可用"不懂就问，卡在哪步问哪步" |
| 解析看不懂，越看越烦 | 人麻了、血压上来了、看懂了但没完全懂、get 不到、同一步卡住 | 解析看了三遍，同一步还是卡住？ | 接"哪步不懂问哪步/分步讲清楚"，主语必须清楚 |
| 反复做错同一类题 | 人麻了、红温、改三遍还错 | 同一类题错三遍，人都麻了？ | 接"定位卡点/举一反三/同类题再练"，别承诺一次清空 |
| 作业/考试时间压力大 | 作业还剩亿点点、难题不过夜、赶 deadline、DDL 是第一生产力 | 晚上 10 点作业还剩亿点点？ | 接"先解决卡住那步/快速看懂思路"，别写夸张恐吓 |
| 自学没人接话 | 搭子、有人能问、卡住不硬扛、i 人卡题不好意思问、情绪价值 | 一个人学，卡住只能硬扛？ | 接"AI/私教/老师按当前功能接话"，陪伴感不等于监督；情绪价值要落到具体动作：能问、能拆、能继续讲 |
| 想逆袭但方法不对 | 弯道超车、偷偷变强、偷感学习*、爆改、卷不动 | 想弯道超车，结果一直原地打转？ | 接"先找短板/按计划练/每天推进一点"，避免保证逆袭；"爆改"只改方法，不承诺结果 |
| 学不动又不敢放下 | 躺又躺不平，卷又卷不动；摆烂；学会了吗？学废了；做题做到 emo；如何呢又能怎* | 暑假躺又躺不平，卷又卷不动？ | 接"把任务拆小/每天 30 分钟/先学一个重点"，按功能事实选；接"如何呢又能怎"时解法必须立刻给出，不能停在摆烂 |
| 碰到难题型有心理阴影 | 被 XX 支配的恐惧、最终 boss、上强度、已老实 | 压轴题：本学期最终 boss？ | 接"拆题型/看得分点/先抓突破口"，不要写包会满分 |
| 想有人划重点 | 课代表、划重点、别让我自己猜 | 期末重点这么多，谁来当课代表？ | 接"洋葱帮你挑重点/排复习顺序"，适合复习、AI 学习系统、私教班 |
| 考前慌，越翻书越乱 | 稳住别慌、先别急、这把稳了、松弛感 | 一看倒计时就慌，越复习越乱？ | 接"先抓高频考点/按薄弱点排顺序"；"这把稳了"只写学生自己的状态，不能当产品承诺；松弛感是结果，不是卖点 |

## 通用开头与收尾

- 吐槽开头：谁懂啊、救命、我去、不是哥们。只做痛点句开头，信息量要在后半句；"不是哥们"偏男生口吻，更适合信息流/社媒；一批文案里最多一两条用开头梗，连用显刻意。
- 自嘲评价：难评。只能评自己的计划和状态（"我这复习计划，难评"），不能指向产品、老师或别人。
- 轻松收尾：爱你老己*。适合社媒向轻文案的收尾，不当主标题，不进硬广。
- 社媒格式梗：`XX be like`（"数学课上的我 be like"）。适合信息流/社媒配图文案，主标题不用。

英文混搭只用学生已经当中文说的那批（flag、DDL、emo、get、boss、NPC、CPU、i 人、be like），不引入要翻译才懂的英文；`PTSD` 这类医疗词同酒/药隐喻规则，不进 K12 投放。

## 慎用表达

以下表达容易过时、显油、语义不清或有承诺/合规风险，默认不用；除非用户或运营明确给了同类语感案例：

- `绝绝子`、`YYDS`、`芭比 Q`、`栓 Q`。
- `拿捏了`、`狠狠拿捏`、`包的`：用在产品侧就是绝对化承诺；写学生自我状态也尽量换更具体的说法。
- `敬自己一杯`、`电子布洛芬` 这类酒/药隐喻，不进 K12 投放。
- 和学习痛点不天然匹配的泛热词。
- 只有情绪没有具体学习动作的句子，例如只写"我真的会谢"。

## 出稿前自检

任一不过就改：

1. 发布测试：痛点句学生会原样发到朋友圈/弹幕吗？
2. 朗读测试：大声读一遍顺不顺口？有没有要想一下才懂的词，比如解码成本高的梗、省主语的比喻？
3. 逻辑测试：解法句的步骤顺序符合产品真实流程吗？有没有跳步？
4. 匹配测试：梗和这个痛点是天然一对，还是硬贴热词？去掉梗，句子还成立吗？

边界不变：每句的主语、动作、指代必须不靠脑补就明确；具体画面优于抽象程度词；整批全是平静疑问句 = 情绪不合格批次；网感和直白冲突时，直白优先。
