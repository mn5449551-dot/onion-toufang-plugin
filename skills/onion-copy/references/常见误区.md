# 文案常见误区（自查清单）

> 出完每套立刻跑这份自查；命中任一就重写。

---

## 误区 1：同义复述

多套文案看似不同，本质是"快、好、对"的不同说法。

**检查**：把多套文案的解法句和"奇效感"部分（副标题 / 双三图最后一句）排成一列，能一眼区分吗？**检查范围是本次输出的全部套数，跨渠道、跨形式并排一起查，不是每个分组单独查。**

**反例**：
```
套 1：洋葱一拍识别准确
套 2：洋葱拍题答案更准
套 3：洋葱让你拍一次就对
```
都在说"准"，**重写至少 1-2 套换不同卖点或换场景**。

**批量版反例**：12 条文案主标题场景各不相同，但解法句里 9 条都是"洋葱AI + 找薄弱点/排好 + 先学哪"——主标题再多样，解法句一个模子也算同义复述。同一卖点内靠换解法落点拉开（产品动作细节 / 使用时刻画面 / 用后变化感受，见 `规格.md` 多套生成），不靠跑偏卖点。

---

## 误区 2：渠道语气混淆

信息流可以用悬念感更强的钩子打断浏览；应用商店/学习机用户在主动比较 App，没耐心猜谜。痛点问句和功能动作型钩子在应用商店都可以用（参 `字段定义-文案.md` 渠道偏好），界线是：问句必须直白点出问题和卖点入口，不能只抛悬念让用户猜。

**反例（应用商店只抛悬念）**：
```
主：看完答案解析更懵了？  ← 有情绪没入口，用户看不出这个 App 凭什么解决
```

**应该（同样是问句，但点出了问题和卖点入口）**：
```
主：拍三遍还不对？  ← 一句对上"识别不准"的处境，暗示"一拍就准"
```

---

## 误区 3：解法变功能清单

副标 / 短句滑向产品说明书。

**反例**：
```
副：洋葱有 AI 错题本 + 分步解析 + 个性化学习路径...
```
→ 列功能没体验感。

**应该**：
```
副：洋葱拍题一拍就准，答案解析次次对  ← 描述使用感受
```

检查：默认学生视角下，文案要能对应具体场景、产品动作和可感知变化。至少写清一个产品动作，例如洋葱一拍、拍题精学、分步解析、看不懂再问 AI；三图关系从规格里的关系库选择，不硬套单一结构。

---

## 误区 4：业务越界

写了 APP 没有的功能。

**反例**：
```
短句 2：AI 自动批改作文打分  ← 拍题精学没有这个
```

**检查**：每套文案描述的功能必须在 `shared/knowledge/卖点库.md` 对应功能的卖点矩阵里；未确认的新能力不要写成既有功能。

---

## 误区 4b：把一个功能的场景套到所有功能

**反例**：给洋葱私教班写“一个人做题没人问、拍一下继续追问”，这是把拍题精学的作业卡题场景套到私教班。

**应该**：先理解当前功能。私教班更适合写诊断、分班、个性化计划、30 分钟课堂、AI+真人辅导、学情报告；拍题精学才适合写一拍定位、分步解析、继续追问。

---

## 误区 4c：为了共鸣而编功能

**反例**：没有资料说明有真人老师，却写“真人私教陪你讲到会”；没有资料说明一次解决全部错题，却写“错题本一次清空”。

**应该**：产品动作不清楚时先查知识库；仍不清楚就先问用户/运营确认是否正确，确认后再写。不能为了共鸣编功能，也不能靠模糊克制的措辞蒙混过去。

---

## 误区 5：产品口径扩张

私教班手册里已有的提分、100%紧贴等表达可以作为业务口径使用；问题在于 Agent 自己凭空扩张承诺。

**反例**：
```
主：30 天包过期中考
副：保证涨分，班级第一
```

**应该**：
```
主：我该怎么学？才能得 A？
副：洋葱私教班先测再学，量身定制提分攻略
```

---

## 误区 6：字数硬卡损失语义

记住：字数是**软约束 / 参考**（合理超出 OK）。如果为了字数硬切让句子没画面感，宁可超字数。

---

## 误区 7：产品腔/内部口径直接进文案

把卖点库或方向卡里的内部描述直接当文案用语。**内部口径包含两类：能力描述词 和 场景描述措辞。两类都不能直接入文案。**

**反例 A：能力描述词照搬**
```
副：AI 定制学习路径，重点规划高效学
```
→ "学习路径 / 重点规划 / 高效学"是产品介绍词，学生不会这么说。

**应该**：
```
副：先补哪、每天学什么，洋葱帮你排好
```

**反例 B：方向卡场景措辞截断入文案**
```
方向卡原文："常常卡在一个小地方"
↓ 错误处理：为控制字数直接截断
主：期末复习卡一步，问谁？
```
→ "卡一步"缺介词，不是自然中文（"卡"是动词，"一步"是量词短语，中间缺"在"），学生不会这么说，读起来也没画面感。

**应该**：从方向卡的场景描述里理解场景本质，再重新用学生口语组织，不截取原文措辞：
```
主：期末复习，不懂的地方卡住了找谁问？
主：复习到一半卡住了，身边没人能问
```

**检查**：每句文案默读一遍，如果能回溯到方向卡的某句原话，说明可能是直接改写而非重新组织——追问"学生真的会这么说吗"，不会说就重写。对照 `渠道.md` 表达红线的替换表；机械换皮无效，标准是学生口语里会不会这么说。

---

## 误区 8：表达要靠猜（省语义 / 模糊比喻）

短句省掉关键语义，或者用要脑补的比喻，用户多想半秒就划走了。

**反例**：
```
主：暑假计划列得满，三天就散了？  ← "散"的是计划还是人？要猜
```

**应该**：
```
主：暑假计划列了一页，没几天就不想学了？  ← 画面具体、语义自明
```

同类问题："期末大题看懂了"应写"期末大题解析看懂了"；"一遇就想合上书"应写"一卡住就想合上书"；"复习卡住了"没说被什么卡住，应写"改错题又卡在同一个步骤"；"同一步卡到人麻了"把"同一个步骤"压成"同一步"，读着要多想一拍，写全才算过关。

范例句不豁免：运营反馈文档和规则文件里的原句照搬前也要过本条自检，出处可信 ≠ 可照搬。

**检查**：每句的主语、动作、指代不靠上下文脑补就明确；具体画面（列了一页）优于抽象程度词（列得满）。

---

## 误区 9：硬贴热梗

为了网感把和痛点无关的热词塞进句子。

**反例**：
```
主：数学不会做，绝绝子
```
→ 梗和痛点没关系，学生不会在这个处境下说这个词，只会尬。

**应该**：梗和痛点天然一对——翻错题本 × 破防、复习没方向 × 开盲盒、计划落空 × 立 flag 原地散架。具体种子库和自检见 `学生视角与网感.md`。

**检查**：匹配测试（这个痛点发生时学生真会用这个梗自嘲吗？去掉梗句子还成立吗？）+ 发布测试（这句学生会原样发朋友圈/弹幕吗？）。梗有时效，以运营最新案例为准。

---

## 误区 10：解法侧玩梗绕弯 / 逻辑跳步

解法句也想玩梗，或者跳过产品流程里的关键一步。

**反例**：
```
副：洋葱 AI 替你开局：先补最弱的那科
```
→ 两个问题：①"开局"是解法侧自己另起炉灶玩梗，绕弯；②没说怎么知道哪科最弱——跳过了"先测"这一步，用户不信。

**应该**：
```
副：洋葱 AI 先帮你测，哪科弱补哪科，不绕路
```
→ 大白话直给，步骤完整（先测 → 再补），最多顺着痛点的梗接一下（"打转"→"不绕路"）。

**检查**：逻辑测试（解法步骤符合产品真实流程吗？）+ 朗读测试（大声读顺不顺口？）。梗负责"像我"，直白负责"可信"。

## 自查口诀

每套文案出完，按这个顺序扫一遍：
1. **场景具体**：真的进入了节点场景吗？有时间、动作（刷题/改错/翻书/写作业/看解析）和卡住的瞬间吗？还是只贴了"暑假/期末"标签？
2. **学生话**：痛点句过发布测试了吗——学生会原样发到朋友圈/弹幕吗？有没有补弱、学习路径、高效学这类产品腔？（对照 `渠道.md` 表达红线替换表）
3. **情绪与梗**：够明显吗（懵、烦、卡死、迷路）？整批全是平静问句不合格；梗和痛点是天然一对吗（误区 9）？过度夸张恐吓也不行。
4. **零推断 + 主语自检**：大声读一遍，每句的主语、动作、指代不靠脑补就明确吗？"三天就散了"这种要猜的表述、"洋葱不懂还能继续问"这种主语错位（应为"看不懂，再问洋葱 AI"）、"卡住了"没说被什么卡住、"同一步"这种名词压缩，立刻改。
5. **同义复述**：本次全部套数跨组并排能区分吗？解法句是不是一个模子？（误区 1）
6. **业务边界**：描述的能力当前功能真的有？AI 私教、拍题精学、AI 学习系统没有混？不确定就先问，不要靠克制措辞蒙混。
7. **渠道与解法体验**：信息流主标够钩子、副标给动作？应用商店/学习机够口语直白？副标/短句是体验感不是功能清单？解法步骤符合产品真实流程、没跳步没玩梗绕弯（误区 10）？
8. **产品口径**：有没有把手册没给的承诺自己加出来？效果写成行为变化了吗（更有方向、下笔不发懵）？
9. **链路完整**：单图一句话讲完痛点和解法；双/三图连读是连续叙事，不是抽象结论并列？
10. **定稿保护**：用户已确认的措辞（私教老师、NPC 老师等）动过吗？动了就改回去。

10 个都过 → 给用户看；任一不过 → 自己改完再给。

## 标杆 Bad Examples（带改写）

> 凝练自旧投放平台 copy generation prompt 的 6 条 bad_example，**每条都标明违反哪个铁律 + 怎么改写**。

### Bad 1：信息流硬广腔（动词陷阱）

**渠道**：信息流 / **形式**：单图

```
主：立即下载洋葱学园 APP
副：限时优惠快来抢
```

❌ "立即下载 / 限时优惠 / 快来抢" 是动词陷阱，信息流要钩子型不要硬广腔，用户立刻反感划走。

✅ 改写（钩子起手 + 默认学生视角；不要写成"娃还卡壳"这种家长腔）：
```
主：一道题卡了快一小时？
副：洋葱一拍，每一步讲到你懂
```

### Bad 2：应用商店多图缺"洋葱"解决方主体

**渠道**：应用商店 / **形式**：三图

```
短句 1：题不会做
短句 2：拍一下
短句 3：当场会
```

❌ 图 2 / 图 3 应至少有一处出现"洋葱"或"洋葱学园"，让用户记住是**谁**在解决。

✅ 改写：
```
短句 1：题不会做
短句 2：洋葱拍一下
短句 3：AI 当场讲
```

### Bad 3：默认学生视角被写成家长腔

**渠道**：应用商店 / 学习机单图 / **形式**：单图

```
主：妈妈再也不用担心我的作业了
副：省心陪伴温暖辅导
```

❌ 用户不指定人群时默认学生视角，"妈妈 / 省心 / 陪伴" 会变成家长腔，缺少学生自己的画面感。

✅ 改写（学生视角 + 产品动作）：
```
主：题不会做？拍一下问 AI
副：5 秒出解析，每一步都讲透
```

### Bad 4：多图 3 个孤立短句没图间关系

**渠道**：应用商店 / **形式**：三图

```
短句 1：高效学习
短句 2：智能 AI
短句 3：拍照解题
```

❌ 三句各说各的，**没有并列 / 因果 / 递进 / 互补 任一关系**；连起来读不成故事——浪费 3 倍成本做单图效果。

✅ 改写（因果关系）：
```
短句 1：题不会做
短句 2：洋葱拍一下
短句 3：AI 当场讲
```

### Bad 5：自己加不存在的强承诺

```
主：30 天提分 30 分
副：保过期中考
```

❌ 手册没有给“30 天提分 30 分 / 保过”这种承诺，不能自己加。

✅ 改写为产品动作和学习过程：
```
主：100 道真题练透 7 大考点
副：考前系统刷题，错题自动收录
```

### Bad 6：为了卡字数砍成电报体（关键词堆砌）⭐

**渠道**：应用商店 / **形式**：三图

```
短句 1：大题卡壳
短句 2：洋葱看点
短句 3：下次自己能写
```

❌ 为了卡字数砍到主谓不全：
- "洋葱看点" 是病句（看什么点？谁在看？）
- "大题卡壳" 只有状态没有场景，钩不住人
- 三句像关键词标签云，不是真人在说话

✅ 改写（口语化通顺，每句 9-12 字在三图 4-12 字建议内；尽量短，但通顺和卖点完整优先）：
```
短句 1：大题卡壳不知咋下笔
短句 2：洋葱一拍看透得分点
短句 3：下次自己能写出来
```

> **核心心法**：**字数仅作参考，少 / 多都 OK**。唯一硬标准是句子通顺自然——读起来像翻译腔或关键词堆砌（如"大题卡壳 / 洋葱看点 / 拿下满分"这种主谓不全的电报体）就重写。
